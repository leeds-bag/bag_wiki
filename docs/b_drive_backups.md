## b-drive backups
_Contributors: Ben Silver_

The b-drives for research data storage are found at: `/uolstore/Research/b`

Within one of your directories on the b-drive, you can run the command:
```bash
cd .snapshots
```
This will take you to a hidden directory where you can see all the snapshots (records of daily changes) of that directory in your b-drive

So if you accidentally delete a file, you can go into the `.snapshots` directory and find the snapshot from the day before and copy the file back to your working directory.
